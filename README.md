This is my implementation of Crafting Interpretors using the Rust programming language.
It is a work in progress, and likely still has a few bugs and/or unintended features, but
I have test cases and have followed the template of the book closely (barring necessary
differences between the languages)

Use of AI: AI was used to help with the creation of test cases to save time. All test
cases were manually checked for accuracy however, as AI often gave incorrect expected outputs.
